# FC Mobile Clone - مشروع لعبة كرة قدم

## ما هذا؟
مشروع جاهز بلغة HTML5 + Canvas يحاكي طريقة لعب FC Mobile:
- جوستيك للحركة (مثل FC Mobile)
- زر تسديد و تمريرة و ركض
- ذكاء اصطناعي للخصم
- نظام اهداف

## كيف تشغل؟
1. فك الضغط zip
2. افتح index.html في المتصفح على الموبايل او الكمبيوتر
3. للتحويل الى APK: استخدم موقع https://www.pwabuilder.com او WebView في Android Studio

## كيف تطوره ليصبح مثل FC Mobile الحقيقي؟
اذا تحب نسخة متقدمة:
- استخدم Unity + C# (افضل محرك العاب كرة قدم)
- او استخدم Godot Engine مجاني
- اضف موديلات 3D للاعبين من Mixamo
- اضف نظام Ultimate Team و انتقالات

الملفات:
- index.html : الواجهة
- style.css : التصميم
- script.js : منطق اللعبة
- assets/ : حط فيه صور اللاعبين والكرة

تقدر تغير الالوان والسرعة من script.js

مطور لك بواسطة Meta AI - اطلب مني اضافة طور اونلاين او طور كارير.
